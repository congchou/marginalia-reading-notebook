# Marginalia · 学术阅读札记设计说明

## 目标

将现有的 Streamlit 生词生句工具升级为一款适合个人长期使用的学术阅读助手。产品采用“学术卡片盒”风格，强调来源、摘录、标签与复习，同时保留轻量、本地和易运行的特点。

## 产品结构

- 今日概览：展示生词、难句、待复习、已掌握等统计，以及最近收录和快捷入口。
- 快速收录：分别录入生词与难句，保存来源、标签和学习状态。
- 阅读资料库：统一搜索和筛选，提供卡片视图和表格视图，并支持编辑和二次确认删除。
- 复习书桌：从待复习与学习中条目随机抽取，展开答案后更新学习状态。

## 数据设计

应用使用本地 SQLite 数据库 `data/marginalia.db`，包含 `vocabulary`、`sentences` 与 `metadata` 三张表。首次启动时自动创建数据表，并将旧的 `vocabulary.csv` 一次性导入。数据库文件和用户数据不进入 Git 仓库。

## 视觉语言

使用米白背景、纸张白卡、棕色强调色、墨绿色辅助色和衬线标题。界面文案以中文为主，英文用于品牌与学术字段。卡片保持克制阴影、清晰留白与批注式标签。

## 可靠性

所有写入使用参数化 SQL 和事务；必填字段会校验；重复条目会提示；删除需要明确确认。纯数据逻辑与 Streamlit 页面分离，以便自动测试。

## 发布

仓库包含源代码、测试、依赖文件、示例说明和运行指南。GitHub 仓库为公开仓库，名称优先使用 `marginalia-reading-notebook`。
